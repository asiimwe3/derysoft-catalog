# DerySoft Store Catalog

Products DerySoft resells: license/activation + installation + support. Official vendor links only — no cracked software, ever (license compliance rule).

## Catalog format

`catalog.csv` columns: `category,name,use,official_link,price_model`
- price_model: one-time / yearly / credits / dongle / subscription / free-with-paid-support

Current: ~185 vetted products across 16 industries. Grows toward 1000 as supplier accounts are opened (see ADDING_PRODUCTS.md).
